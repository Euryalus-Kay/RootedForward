# Phase 9. Print production spec

## Version A · rigid boards

- Four boards, 36 × 48 in portrait, matte print on 4.7mm foam board
  (the Staples engineering-print-to-board path or any large-format
  flatbed shop), displayed on black museum floor stands.
- Files: `out/board-N.pdf` (exact trim, 36 × 48) and
  `out/board-N-bleed.pdf` (36.5 × 48.5, artwork centered, linen
  carrying into a quarter-inch bleed on all sides). Send the trim
  file unless the shop asks for bleed; nothing lives within 1.4in of
  any edge except full-bleed imagery.
- Vector type throughout, outlined to paths (no fonts embedded or
  needed, same pipeline as the shipped 72×24 banner). RGB color; the
  shop converts at the RIP. The linen ground is #EDE6D6, carbon type
  #1C1A17, and the red #B0322B should stay a warm brick red in
  conversion, not shift pink.
- 300dpi target at placed size for raster imagery. The build prints
  an effective-dpi audit per image. Final audit, August 28, 2026:
  every placement sits between 218 and 415dpi except three period
  enlargements that run 104 to 121dpi (the Graham lithograph as the
  sheet-1 and banner-1 hero, the 1871 plan and the Rosskam photograph
  as full-bleed banner bands). Those three use the largest scans the
  holding archives publish (LOC and BPL masters), are halftone or
  engraved sources that enlarge gracefully, and read at their real
  viewing distances. Accepted deliberately; noted here so the print
  shop is not surprised.

## Version B · retractable banners

- Four banners, 33 × 81 in. Files: `out/banner-N.pdf` (33 × 81 trim)
  and `out/banner-N-bleed.pdf` (33.5 × 88.5, the same artwork with a
  quarter inch of bleed on the sides and top and the bottom extended
  7.25in with the plinth color for cassette wrap). If the chosen
  printer's template is 33 × 88, send the bleed file, top-aligned;
  its extra bottom is all sacrificial plinth.
- The design assumes the bottom 8in of the visible face can be lost
  to the cassette without cost; nothing that must be read sits below
  64in from the top (17in from the floor).
- Match the printer's own template for cassette insertion before
  ordering; the two delivered geometries cover the common cases, and
  the build re-runs at any other height by editing GEOM in
  `build-exhibit.mjs`.

## The QR

- Both sheet-4 files carry a QR encoding
  `https://rooted-forward.org/go/exhibit`, re-pointable forever in
  `src/lib/qr-links.ts` (slug `exhibit`, currently aimed at the Walk
  Hyde Park tour page). The build decodes the code off the rendered
  print file and refuses to finish if it does not scan or points
  anywhere else. The slug goes live with the next deploy.

## Rebuild from source

```bash
node print/exhibit/gen-maps.mjs        # redraw the two map plates
node print/exhibit/prep-images.mjs     # stage and normalize imagery
node print/exhibit/gen-qr.mjs          # the /go/exhibit code
node print/exhibit/build-exhibit.mjs --final
```

Sources of record: `panels/*.html` and `panels/system.css` (layout and
copy), `assets/` (staged plates and imagery), the fact registry at
`data/exhibit/facts.json` for every number. The design-canvas mirror
is regenerated by `gen-canvas.mjs` and republished to the same
artifact.
